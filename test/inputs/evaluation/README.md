# Empirical evaluation fixtures

These compact, offline fixtures reproduce the PlantBiophysics-only parts of
the evaluation notebooks in `VEZY/PlantBiophysics-paper`.

## Medlyn et al. data

The source dataset is *Tumbarumba Gas Exchange* (Medlyn, Pepper, and Keith,
2015), DOI `10.6084/m9.figshare.1538079.v1`, distributed under CC BY 4.0.

- A-Ci curves: Figshare file `3402635`, SHA-256
  `789b9ab619b6017a5234ed6790f85ac5c6acf4ddb46631f6156cc0b8830e6e88`.
- Spot measurements: Figshare file `3402638`, SHA-256
  `d91403a7785ab65f7bc1e7c6d76aa826a56312db442aeaa6e40db88314eaa979`.

`medlyn_global.csv` contains the 673 quality-filtered curve observations and
only the meteorology, model drivers, and measured A, E, Gs, and Tl columns.
The regression test applies the paper's `Ca > 150 ppm` filter, leaving 536
aligned observations. `medlyn_global_parameters.csv` freezes the 46 per-curve
FvCB and Medlyn fits generated by the paper workflow so model fitting cannot
mask a simulation regression. `medlyn_daily.csv` is the paper's pinned six-row
case for tree 3 on 2001-11-14.

The reference statistics come from the paper repository's `main` history:
global values are the full-precision values behind `statistics.csv` at commit
`c078fcf9ed8ce56bcb8bcd5703fdc6239cbf8621`; daily values come from the
main-branch notebook output. Tests use one-sided tolerances, so improved model
quality passes. The compact global inputs and frozen fit table were extracted
from the paper workflow's adapted output at commit
`b454566ed9ac346f455c6224e9746fb2525c876c`.

## Schymanski et al. data

The Schymanski figure-6a inputs were already tracked under
`docs/src/data/schymanski_et_al_2017`; the tests reuse those files rather than
duplicating them. They originate from `schymans/Schymanski_leaf-scale_2016`.
That upstream repository declares GPL-3.0, while its Zenodo record uses the
label "Other (Open)"; retain this provenance if the existing files are moved or
redistributed separately.
